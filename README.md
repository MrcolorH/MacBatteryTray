# MacBatteryTray

原生轻量级 macOS 外设电量监控工具。支持 2.4G 无线接收器与蓝牙外设的剩余电量采集，并与 macOS 控制中心（Control Center）磁贴及桌面小组件无缝集成。

## 特性

- **2.4G 接收器原生支持**：解决 macOS 原生无法读取 2.4G 无线键鼠、耳机电量的痛点。
- **蓝牙设备无缝接入**：基于系统 IOKit 注册表，无需额外蓝牙权限弹窗，性能损耗趋近于零。
- **自定义展示开关**：支持在菜单栏中一键开启或关闭“展示蓝牙设备电量”，自主决定面板呈现内容。
- **控制中心与桌面小组件**：支持 macOS 控制中心快速磁贴（ControlWidget）与桌面小组件（WidgetKit），轻点即可即时刷新。
- **开机自动启动**：基于 macOS 原生 `SMAppService`，无需任何驻留助手进程。

## 支持的外设品牌与方案

- **雷蛇 (Razer)**：2.4G 鼠标（毒蝰、炼狱蝰蛇系列等）、梭鱼系列无线耳机
- **罗技 (Logitech)**：HID++ 协议无线键鼠
- **赛睿 (SteelSeries)**：Arctis / 无线外设
- **国产公模方案**：CompX (0x3554)、容渊 (0x3151)、Xenta 等国产 3395/3950 常见方案
- **通用蓝牙外设**：标准蓝牙鼠标、键盘与音频设备

## 本地编译构建

本项目支持直接使用 Swift 原生单命令构建，无需庞大的 Xcode IDE 依赖：

```bash
# 生成本地签名并完整编译 App Bundle
./scripts/build.sh
```

构建产物将输出至 `build/MacBatteryTray.app`。
