# MacBatteryTray

一款为 macOS 设计的原生轻量级 **2.4G 无线外设多设备电量监控看板**。

---

### 💡 重要产品定位声明

> **请在下载前阅读：**
> 
> 本软件主要用于解决 **macOS 接入 2.4G 无线接收器后，系统完全无法读取外设剩余电量** 的核心痛点。
> 
> - **如果您的设备群全部是纯蓝牙外设**（如 Apple 原生 Magic 系列、普通蓝牙耳机、纯蓝牙键鼠等）：  
>   macOS 系统自带的控制中心、蓝牙菜单以及原生电池小组件中**本来就已经能够直接显示电量**，**此时您其实并不需要使用本软件**。
> 
> - **如果您的桌面接入了 2.4G 无线接收器**（如雷蛇、罗技、赛睿、艾石头，以及各类搭载 CompX、容渊等公模方案的高回报率电竞鼠标、机械键盘、无线耳机），或者您希望将 **2.4G 外设与蓝牙设备在同一个桌面小组件中统一聚合展示**，那么 MacBatteryTray 将是您的最佳解决方案。

---

### ✨ 核心特性

- 🎯 **2.4G 硬件电量深度直读**：通过原生 IOKit 深入读取雷蛇、罗技 HID++、赛睿、CompX、容渊等常见 2.4G 接收器方案，摆脱臃肿且常在 Mac 上断更的官方驱动（如雷云）。
- 🖥️ **纯桌面小组件生态**：不占用宝贵的顶部任务栏空间，提供现代美观的 macOS 桌面电池环小组件（支持小、中、大三种尺寸）。
- ⚙️ **防误触与独立操作区**：小组件右上角提供独立的齿轮设置（⚙️）与刷新（🔄）按钮；小组件背景自带静默交互层，平时随意点击桌面或小组件背景**绝不会误弹窗打扰**，仅点击齿轮时才唤起 App。
- 📐 **零重叠物理隔离架构**：重构小组件为垂直流布局，无论连接 1 个、2 个、3 个、4 个或更多外设，圆环与操作按钮永远物理隔离，绝不发生遮挡。
- 👻 **无感静默守护**：双击启动即弹出优雅的原生可视化面板；点击红叉关闭窗口后，**Dock 栏图标自动隐形**，后台以 0% CPU 默默为桌面小组件供数；面板内提供「退出服务」按钮与二次确认防护。
- 🔄 **内置 GitHub 更新检测**：面板内集成「软件更新」模块，自动通过 GitHub Releases 检测最新版本，支持一键直达下载。

### 🎮 支持的 2.4G 协议与品牌方案

- **雷蛇 (Razer)**：2.4G 鼠标全系列（毒蝰 Viper 系列、炼狱蝰蛇 DeathAdder 系列、巴塞利斯蛇等）、梭鱼 Barracuda 系列无线耳机等；
- **罗技 (Logitech)**：支持 HID++ 协议的 2.4G Lightspeed 无线鼠标与键盘；
- **赛睿 (SteelSeries)**：Arctis 赛睿无线系列外设；
- **国产热门方案**：CompX (0x3554)、容渊 (0x3151)、Xenta 等国产 3395/3950 主流三模无线键鼠方案；
- **蓝牙设备（可选开启）**：在设置面板中可自由开启「展示蓝牙设备电量」，将已配对的标准蓝牙键鼠电量一同汇入桌面小组件。

### 📥 下载与安装

1. 从 [GitHub Releases](https://github.com/MrcolorH/MacBatteryTray/releases/latest) 下载最新的 `MacBatteryTray-vX.X.X.zip`；
2. 解压后将 `MacBatteryTray.app` 拖入 `/Applications`（应用程序）文件夹；
3. 打开应用，首次启动在「系统设置 ➔ 隐私与安全性 ➔ 输入监控」中允许本应用（用于读取 USB 接收器底层 Feature Report）；
4. 右键点击 Mac 桌面空白处 ➔ 选择「编辑小组件」➔ 搜索「外设电量」即可添加小组件至桌面。
